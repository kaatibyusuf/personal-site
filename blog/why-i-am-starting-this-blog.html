How to add a post

  1. Create a file in the posts folder, for example my-new-post.md.
  2. Put these lines at the very top, then write below them:
---
title: My new post
date: 2026-12-01
summary: One sentence that shows on the blog page.
---
  1. Run node build-blog.js, then commit and push.

Use draft: true in those top lines to hide a post until it is ready.
